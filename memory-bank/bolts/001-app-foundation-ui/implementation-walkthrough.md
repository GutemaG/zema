## Implementation Walkthrough: app-foundation-ui (bolt 1 of 3)

### Summary

The default counter template is replaced by a themed placeholder app named "Zema". The
app gets the design-system color tokens for both palettes, a dark theme and text theme
built from them, and bundled Inter and Noto Sans Ethiopic fonts with their licenses
registered. Strict analyzer rules now apply to both workspace packages, and a GitHub
Actions workflow checks formatting, analysis and tests.

### Structure Overview

Everything about the look of the app lives in `apps/mobile/lib/app/theme/`: tokens,
palette enum, typography, spacing and the theme builder. `lib/app/` holds the root
widget and app-level setup (font licenses). `main.dart` registers the licenses and starts
the app. Fonts, license texts and the icon source images are assets under
`apps/mobile/assets/`. Navigation, state management and localization are not added yet.
They arrive in bolt 2.

### Key Decisions

- **Fonts from Google Fonts, not the GitHub release zips**: the upstream release zips
  (34 MB for Inter) downloaded at about 10 KB/s. Google Fonts serves the same OFL
  families as individual static TTFs (about 3 MB in total). The OFL texts come from the
  google/fonts repository and name the upstream projects.
- **Separate typography file**: `zema_typography.dart` was split out of the theme builder
  so later bolts (lyrics styles, Settings) can reuse the family names and the Ethiopic
  line height without importing the whole theme.
- **Line height on every text style**: Ethiopic can appear in any style through the font
  fallback, so all styles use ≥ 1.4, not only Ethiopic-specific ones.
- **iOS project setting reverted**: flutter_launcher_icons rewrote
  `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS` from `YES` to `AppIcon`,
  a known tool bug. That change was reverted; only the icon images were kept.
- **Icon drawn with the bundled font**: no image tools were available, so a throwaway
  Flutter test rendered ዜ with Noto Sans Ethiopic Bold to PNG and was then deleted.

### Deviations from Plan

- Font source changed from the upstream GitHub releases to Google Fonts (see Key Decisions).
- Added `zema_typography.dart`, which the plan did not list.
- The app smoke test, token test, no-color-literal test and Ethiopic render test are
  written in Stage 3. Until then `apps/mobile` has no tests, so the CI `flutter test`
  step would fail at this point.
